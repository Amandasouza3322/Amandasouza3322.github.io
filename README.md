# Portfólio — Amanda Souza

Site de portfólio profissional desenvolvido com HTML, CSS e JavaScript, preparado para publicação gratuita no GitHub Pages.

## Conteúdo
- Apresentação profissional
- História de carreira conectando gestão operacional e Ciência da Computação
- Projeto acadêmico Spoleto Stock
- Competências técnicas e experiência profissional
- Links para GitHub e contato

## Como visualizar localmente
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório chamado `Amandasouza3322.github.io` no GitHub.
2. Deixe o repositório público para o GitHub Pages gratuito.
3. Envie o conteúdo desta pasta para a raiz do repositório (não envie o ZIP).
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
7. Aguarde alguns minutos e abra `https://Amandasouza3322.github.io`.

## Personalizar antes de publicar
- Atualize o link do LinkedIn em `index.html`.
- Preencha seu e-mail no botão com `id="copy-email"` (atributo `data-email`).
- Confira o endereço do repositório do Spoleto Stock no link correspondente.
- Revise as competências para manter apenas aquelas que você consegue demonstrar em entrevista.
- Confira o código e não publique senhas, tokens, dados reais de funcionários, fornecedores ou informações internas.

## Sobre o Spoleto Stock
O site apresenta o Spoleto Stock como projeto acadêmico independente inspirado na experiência profissional da autora. Ele não é apresentado como um produto oficial da marca.
